# WEBSTUDIO Landing Page

Це простий статичний лендінг для вебстудії з адаптивною версткою та секціями:

- заголовок з навігацією та контактами
- герой-секція з закликом до дії
- секція "Features"
- секція "Team"
- секція "Portfolio"

## Файлова структура

- `index.html` — основна сторінка
- `css/main.css` та інші файли в `css/` — стилі для макета, хедера, героя,
  мобільного меню, модального вікна, портфоліо, команди тощо
- `images/` — графіка та іконки, що використовуються на сторінці

## Запуск

Відкрийте `index.html` у браузері або розгорніть сайт через локальний сервер для
тестування адаптивності.

## Рекомендації

- Для локального перегляду можна використовувати будь-який простий HTTP-сервер,
  наприклад:
  - `python3 -m http.server` у корені проєкту
- Перевірте адаптивність на різних ширинах екрану

## Примітки

Проєкт не містить JavaScript-файлів у корені, а тільки HTML, CSS та графічні
ресурси.
